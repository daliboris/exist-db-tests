# User management

Creating multiple users in eXist-db using application package

[without-script](src/without-script) - example of default behavior of the eXist-db application with multiple users

[without-script](src/without-script) - example of creating groups and multiple users in `post-install.xql` script

[with-local-secrets](src/with-local-secrets) - example of creating groups and multiple users in `post-install.xql` keeping secrets locally, not synchronized with git repository

[install](src/install) - scripts for creating Docker instance of eXist-db and testing build and deployment of sample applications

Use [user-management.code-workspace](user-management.code-workspace) to work with projects in Visual Studio Code.
